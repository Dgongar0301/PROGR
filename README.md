# ☕ PROG – Programación

Repositorio dedicado a la asignatura de **Programación (PROG)**, perteneciente al ciclo formativo de **Desarrollo de Aplicaciones Web (DAW)**.

En este repositorio se recopilan las prácticas, ejercicios y proyectos realizados durante el curso, trabajando principalmente con el lenguaje de programación **Java** y los fundamentos de la programación orientada a objetos.

## 🎯 Objetivos de la asignatura

- Comprender los fundamentos de la programación.
- Aprender a desarrollar programas utilizando Java.
- Conocer y aplicar los diferentes tipos de datos y variables.
- Utilizar operadores y expresiones para realizar operaciones.
- Implementar estructuras de control y repetición.
- Desarrollar programas mediante funciones y métodos.
- Comprender los fundamentos de la programación orientada a objetos.
- Trabajar con clases, objetos, atributos y métodos.
- Aprender a utilizar arrays y estructuras de almacenamiento de datos.
- Gestionar errores y excepciones.
- Aplicar buenas prácticas de programación y organización del código.

## 🛠️ Tecnologías y herramientas

Las principales tecnologías y herramientas utilizadas en este repositorio son:

- **Java:** Lenguaje de programación principal utilizado para desarrollar aplicaciones.
- **JDK (Java Development Kit):** Kit de desarrollo necesario para compilar y ejecutar programas Java.
- **JVM (Java Virtual Machine):** Máquina virtual encargada de ejecutar el código Java.
- **Programación orientada a objetos (POO):** Paradigma basado en clases, objetos, atributos y métodos.
- **Visual Studio Code / IntelliJ IDEA:** Entornos de desarrollo para escribir, ejecutar y depurar código Java.
- **Git y GitHub:** Control de versiones y gestión del repositorio.

## 📖 Contenidos de la asignatura

A lo largo del curso se trabajan diferentes conceptos relacionados con la programación y el desarrollo de aplicaciones:

1. **Introducción a la programación:** Conceptos básicos, algoritmos y lógica de programación.
2. **Fundamentos de Java:** Sintaxis, estructura de un programa, variables y tipos de datos.
3. **Operadores y expresiones:** Operadores aritméticos, relacionales y lógicos.
4. **Estructuras de control:** Condicionales (`if`, `else`, `switch`).
5. **Estructuras repetitivas:** Bucles `for`, `while` y `do-while`.
6. **Métodos y funciones:** Creación, utilización, parámetros y retorno de valores.
7. **Arrays y cadenas:** Almacenamiento y manipulación de datos.
8. **Programación orientada a objetos:** Clases, objetos, atributos, métodos y constructores.
9. **Herencia y polimorfismo:** Reutilización de código y relaciones entre clases.
10. **Gestión de excepciones:** Tratamiento de errores mediante `try`, `catch` y `finally`.
11. **Colecciones:** Introducción a estructuras como listas y otras colecciones de Java.
12. **Depuración y buenas prácticas:** Identificación de errores, mantenimiento y organización del código.
